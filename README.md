# lab7_architecture_ddd
## Архитектура

Проект реализован с использованием слоистой архитектуры и принципов DDD-lite.

### Слои:
- Domain — доменная модель и бизнес-правила
- Application — use-case оплаты заказа
- Infrastructure — реализации репозиториев и платёжного шлюза
- Tests — тесты бизнес-логики без использования базы данных

### Результат
Доменная логика изолирована от инфраструктуры.
Use-case управляет сценарием работы системы.
Все ключевые бизнес-инварианты покрыты тестами.
